# 🚀 Blockchain Educacional: Aprendendo Blockchain de Forma Simples e Interativa

## 💡 Sobre o Projeto

O projeto "Blockchain Educacional" nasceu com um propósito claro: desmistificar a tecnologia Blockchain. Sabemos que, para muitos, os conceitos fundamentais do Blockchain podem parecer complexos e abstratos. Nossa missão é transformar essa percepção, tornando o aprendizado acessível, intuitivo e, acima de tudo, divertido.

Para isso, desenvolvemos uma aplicação interativa que simula de forma simplificada os pilares do Blockchain, como blocos, hashes e a própria cadeia de blocos. A ideia é que o usuário possa aprender brincando, explorando os módulos e respondendo a quizzes que solidificam o conhecimento adquirido, funcionando como um "jogo simples" educacional.

## ✨ Funcionalidades Principais

*   **Módulos Interativos:** 🔗 Explore os conceitos de Hash, Blocos e a Cadeia Blockchain através de interfaces visuais e dinâmicas.
*   **Quizzes Educacionais:** 🧠 Teste seu conhecimento com quizzes específicos para cada módulo e um quiz final abrangente.
*   **Onboarding Guiado:** 🧭 Uma introdução amigável para novos usuários, explicando a proposta do projeto.

## 💻 Como Rodar a Aplicação

Para rodar o "Blockchain Educacional" em sua máquina local, siga os passos abaixo:

### Pré-requisitos ✅

Certifique-se de ter o [Node.js](https://nodejs.org/en/) (que inclui o npm) ou o [Yarn](https://yarnpkg.com/) instalados em seu sistema.

### Instalação 📦

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Gomes/Blockchain_Educacional.git
    cd Blockchain_Educacional
    ```
    *(Note: Assuming a GitHub repository for the clone command based on typical project setups. If this is incorrect, please provide the actual repository URL.)*

2.  **Instale as dependências:**
    Utilizando npm:
    ```bash
    npm install
    ```
    Ou utilizando Yarn:
    ```bash
    yarn install
    ```

### Executando a Aplicação ▶️

Para iniciar o servidor de desenvolvimento e ver a aplicação em seu navegador:

Utilizando npm:
```bash
npm run dev
```
Ou utilizando Yarn:
```bash
yarn dev
```

A aplicação estará disponível em `http://localhost:5173` (ou outra porta indicada no terminal).
